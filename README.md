# claude-code-pm-capstone
A full-cycle PM capstone project run entirely with Claude Code — research synthesis, prototyping, statistical experiment design, stakeholder pressure-testing, and leadership communication, all built on a real (Nudge) product case study. Includes a portable prompt and onboarding kit to reuse the workflow on any product.

## What's in This Repo

**Case study:** Nudge, a consumer fintech app, is losing 30-day retention (44% → 37%). This project runs that problem end to end — from raw Slack thread to a leadership-ready recommendation — using Claude Code as the working collaborator throughout.

| Folder | Contents |
|---|---|
| `CLAUDE.md` | Living project context, kept current every session — start here. |
| `research/` | Interview synthesis, NPS analysis, competitive matrix + Reddit sentiment. |
| `docs/` | Decision brief, PRD, spec/design reviews, QA checklist, objection log, recommendation memo, quarterly deck + speaker notes, onboarding guide + demo script. |
| `data/` | Pilot metric analysis, full diagnosis, and a properly-powered experiment design (significance, power, sample size). |
| `prototype/` | Interactive HTML/CSS/JS prototype, iterated v1 → v3 against usability feedback. |
| `stakeholders/` | Profiles used to pressure-test decisions via simulated stakeholder review. |
| `skills/` | Reusable, single-prompt PM workflows (status updates, research synthesis, competitive checks). |
| `agents/` | A built-and-verified weekly metrics digest agent, with a documented path to production. |
| `change_log.md` | Full chronological history of the project — the detailed source of truth. |
| `archive/` | Superseded early drafts, kept for reference. |

**Reuse it:** `docs/capstone-session.md` has a portable prompt for running this same workflow on a different product, plus a confidence audit of every artifact here. `docs/onboarding-guide.md` and `docs/onboarding-demo-script.md` are a 5-minute read and a 15-minute live demo for onboarding someone new to Claude Code.

**Honesty flags baked in:** the pilot data's statistical significance, simulated-vs-real stakeholder reviews, and unconfirmed dataset provenance are all called out inline rather than smoothed over — see `CLAUDE.md` for the current list of open questions.
